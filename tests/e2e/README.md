# Pruebas de extremo a extremo

Pruebas con **Playwright** que recorren la aplicación completa desde el navegador: cargar un PDF → ver el resultado → encontrarlo en el historial → corregirlo.

Se configuran en la Fase IV, cuando el frontend y la API estén integrados. Las pruebas unitarias y de API viven en `backend/tests/` y `ml/tests/`.
